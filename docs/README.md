## 维护约定

1. 检查记录命名为 `YYYY-MM-DD-topic.md`，注明代码版本、工作区状态、范围和日期。
2. 每项结论标明依据：源码检查、静态包证据、替身回归、构建检查或真机结果；不能互相替代。
3. 修改记录包含问题、对应文件、最终行为、验证方式和剩余限制。
4. 测试数量与构建结果是记录当时的快照；后续修改需更新记录或新增日期记录。
5. 安装包注明版本、路径和摘要；路径以仓库为基准。私钥、口令、用户真实坐标和未脱敏日志不写入文档。
6. 外部资料记录来源与分析限制；不把类名、字符串或推断写成已验证的运行行为。
7. 新记录加入本索引。迁移文档时保留旧入口，避免已有链接失效。
